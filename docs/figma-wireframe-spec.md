# Figma Wireframe Specification

## Frames to create
1. **Landing / Home**
   - Hero with CTA (Explore tracks, Join internship)
   - Track cards
   - Testimonials
   - FAQ and pricing/refund explainer

2. **Internship Track Detail**
   - Header (eligibility, duration, projects)
   - G1/G2/G3 cycle timeline
   - Mentor profiles
   - Enroll with coupon input

3. **Auth Flow (OTP)**
   - role selector
   - phone/email input
   - OTP verify

4. **Student Dashboard**
   - star progress bar (G1-G4)
   - assigned tasks
   - refund tracker
   - live session schedule

5. **Mentor Dashboard**
   - assigned interns
   - submissions queue
   - evaluation form

6. **Admin Dashboard**
   - user management table
   - internship CRUD
   - coupon/refund panel
   - sponsor and mentor pipeline metrics

7. **Interview Lab**
   - left panel: coding prompt + test cases
   - center: editor + run/submit
   - top-right: live camera panel
   - bottom-right: interviewer notes + MCQ panel

8. **Certificate Template**
   - student details
   - unique verification ID / QR
   - mentor/admin signatures
   - sponsor co-branding slots
